# Мопс і шифри

Навчальна майстерня з прикладної криптології, варіант 28. Ставісюк Олександра Сергіївна.

Потрібен Python 3.10 або новіший. Сторонні бібліотеки не потрібні.

1. Виконайте `python app.py` у каталозі проєкту.
2. Відкрийте http://127.0.0.1:8000.
3. Виберіть алгоритм, натисніть «Приклад варіанта» та «Обчислити».
4. Збережіть протокол за потреби. Для зворотної операції RSA вставляйте блоки через пробіл.

`python -m unittest -v` запускає контрольні перевірки.

Навчальні параметри RSA та класичні шифри призначено для демонстрації.
